# forty-two-watts — Home Assistant add-on repository

Unified Home Energy Management System for Home Assistant.

## Install

1. In Home Assistant, go to **Settings → Add-ons → ⋮ → Repositories**.
2. Add this repository URL:

   ```
   https://github.com/erikarenhill/ha-addon-forty-two-watts
   ```

3. Refresh the add-on store, find **forty-two-watts**, and click **Install**.
4. Start the add-on, then open the Web UI to run the setup wizard.

- [forty-two-watts](forty-two-watts/) — the EMS itself.
